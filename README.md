# The Travel Place — Brand Pitch Deck

A self-contained interactive pitch deck for **The Travel Place (TTP)** brand identity proposal.

## Open

Open `pitch.html` directly in Chrome or Edge. No server or build step needed.

## Controls

| Key | Action |
|-----|--------|
| `→` / `Space` | Next slide |
| `←` | Previous slide |
| `F` | Toggle fullscreen |
| `P` | Toggle presenter notes |
| `?` | Keyboard shortcuts |
| Swipe | Touch navigation |
